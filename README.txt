Images are hosted remotely on Unsplash and require internet connectivity to display.

How to deploy:
1. Download and extract the package.
2. Back up your existing GitHub Pages repository files.
3. Upload these files to the repository root (same location as index.html).
4. Commit changes to the branch GitHub Pages publishes.
5. Wait for deployment and test your website on mobile and desktop.

Keep your Google verification meta tag in index.html. The existing tag is included.
Review social links before publishing: the Facebook and Instagram links currently point to generic homepages.
